# two-worlds

Two independent front-end projects live in this repository:

- **The Two Worlds** (repository root): an exhibition in ten rooms on Plato, Aristotle and the question of what is real. `npm install && npm run dev`.
- **[Essential Life Upgrade](life-upgrade/)** (`life-upgrade/`): a personal shopping decision engine. It answers what to buy next to improve your life, and what not to buy yet. `cd life-upgrade && npm install && npm run dev`.
