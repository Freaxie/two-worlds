# Why Didn't Ancient People Write About Dinosaurs?

*A YouTube Short production package: cinematic documentary, 9:16, about 1:30.*

> **Logline:** Humans have walked above dinosaur bones for 300,000 years, yet no ancient text clearly describes one. Ancient people *did* find giant bones and wrote about them. The real gap is that **finding a fossil and understanding it are two completely different things.**

## Accuracy ground rules (for everyone touching the edit)

1. **Real objects get provenance tags; generated images get `RECONSTRUCTION` / `ILLUSTRATIVE` tags.** No generated image may look like a real artifact (no AI "ancient tablet with a dinosaur").
2. **Keep the hedge words:** *clearly*, *perhaps*, *most*, *so-called*, *maybe*. Each one corresponds to a specific evidence limit (see 02 → "Wording choices").
3. **No myth is presented as fossil-inspired fact.** The griffin–*Protoceratops* idea in particular is contested by recent specialist work (Witton & Hing 2024).
4. If a fact changes, update **01-research-dossier.md** first, then the script.
