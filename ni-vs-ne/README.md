# Ni vs Ne

An interactive exhibition on two ways of navigating possibility — Ni (convergence) and Ne (divergence).
React + Vite + Framer Motion + hand-built SVG.

```sh
npm install
npm run dev           # local dev server
npm run build         # production build to dist/
npm run build:single  # one self-contained HTML file in dist-single/
```

Rooms: hero · 01 core difference · 02 one idea, two minds · 03 two questions · 04 time & possibility ·
05 experiment · 06 failure modes · 07 not opposites · 08 thread & web.

Scroll-scrubbed diagrams play once on entry instead on narrow screens, and all motion respects
`prefers-reduced-motion`.
