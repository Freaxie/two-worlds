# Ti vs Te

An interactive exhibition on two kinds of logic — Ti (the internal model) and Te (the external system).
Third in the series with `../ni-vs-ne` and `../p-vs-j`, built on the same system: React + Vite + Framer Motion + hand-built SVG.

```sh
npm install
npm run dev           # local dev server
npm run build         # production build to dist/
npm run build:single  # one self-contained HTML file in dist-single/
```

Rooms: hero · 01 core difference · 02 one problem, two minds · 03 two questions · 04 depth & reach ·
05 experiment · 06 failure modes · 07 not opposites · 08 model & machine.
