# P vs J

An interactive exhibition on two ways of meeting an unfinished world — P (openness) and J (closure).
A companion to `../ni-vs-ne`, built on the same system: React + Vite + Framer Motion + hand-built SVG.

```sh
npm install
npm run dev           # local dev server
npm run build         # production build to dist/
npm run build:single  # one self-contained HTML file in dist-single/
```

Rooms: hero · 01 core difference · 02 one trip, two minds · 03 two questions · 04 time & the deadline ·
05 experiment · 06 failure modes · 07 not opposites · 08 line & door.
